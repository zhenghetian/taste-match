# 添加好友与邀请加入原型

直接用浏览器打开本目录 `index.html`，不需要登录、安装依赖或启动后端。产品服务器采用静态资源白名单，本目录不作为产品服务路由开放。

## 体验流程

1. 在邀请人视角查看并复制演示邀请码 `AH7K2M`。
2. 点击右上角“切换为朋友视角”，输入邀请码与至少两字的名字。
3. 接受邀请后在好友列表进入聊天，发送一条模拟消息。
4. 切回邀请人视角，可看到填写的朋友名字，并在同一段模拟聊天中查看消息。

无效邀请码和过短名字会提示错误。返回聊天列表或切换视角不会丢失本次页面中的消息；刷新页面会重置全部模拟数据。

## 范围与暂定规则

这是独立单页原型，数据仅在页面内存中，不发起业务网络请求，不存储真实账号，不连接产品数据库。切换视角模拟两个人，不代表跨设备通信。分享按钮仅展示准备分享的状态；复制内容明确标记为演示，不提供实际邀请链接。

页面中的有效期7天、最多20人是待确认的产品方案，原型未实现计时和人数限制。真实注册、账号验证、好友关系、邀请撤销、跨设备聊天和公网访问均待开发。
