# 添加好友与邀请加入原型

本目录是早期单页交互原型，数据仅在内存中。**真实能力已接入产品主入口** `signal-mvp.html` / `server.mjs`。

## 产品入口（请用这个）

1. `npm start` 后打开 http://127.0.0.1:4173
2. 登录后进入「我的」→「好友」，或「设置」→「好友邀请」
3. 复制 / 分享好友邀请链接（`/?friend_invite=FH...`）给**已注册**朋友
4. 对方登录并接受后，双方出现在好友列表，可聊天

规则：邀请码前缀 `FH`，有效期 7 天，最多 20 人；与闭测注册邀请码（`AH...` / 主邀请码）相互独立。

## 本原型页面

直接打开 `index.html` 仍可本地演示旧交互，不连接数据库。
