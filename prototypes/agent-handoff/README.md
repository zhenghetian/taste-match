# Agent 代回与接管原型

本目录是早期单页交互原型（内存模拟、固定回复）。**产品聊天页已实现自动代回与建议草稿两种模式。**

## 产品入口（请用这个）

1. `npm start` → http://127.0.0.1:4173
2. 完成一次回声对话（或好友聊天）后打开聊天页
3. 点击 **Agent 建议**，选择 **同意并开启自动代回**，或继续使用建议草稿。
4. 自动代回直接发送并标注 **Agent 代回**；建议草稿需确认发送，标注 **Agent 建议**。
5. 点击 **我来聊** 或直接发送消息，即可接管当前对话。

说明：开启 LLM 时设置 `ANHAO_LLM_ENABLED=true` 并配置 Anthropic 兼容凭证。自动代回仅发送模型结果，失败会停止；建议草稿在模型关闭时使用备用内容。开关按会话持久化在 SQLite。

## 本原型页面

直接打开 `index.html` 仅作旧交互对照，不代表线上行为（原型仍演示“自动代回”）。
