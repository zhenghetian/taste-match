# Agent 代回与接管原型

本目录是早期单页交互原型（内存模拟、可自动插入回复）。**产品实现已改为 suggest-then-confirm，不会自动发送。**

## 产品入口（请用这个）

1. `npm start` → http://127.0.0.1:4173
2. 完成一次回声对话（或好友聊天）后打开聊天页
3. 点击 **Agent 建议** → **同意并开启建议** → **生成回复建议**
4. 草稿进入输入框，可修改；点击发送后，气泡标注 **Agent 建议**
5. 关闭建议或清空输入即取消待发送标注

说明：开启 LLM 时设置 `ANHAO_LLM_ENABLED=true` 并配置 Anthropic 兼容凭证；关闭时使用备用草稿。草稿与开关按会话持久化在 SQLite。

## 本原型页面

直接打开 `index.html` 仅作旧交互对照，不代表线上行为（原型仍演示“自动代回”）。
