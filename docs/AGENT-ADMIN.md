# Agent 与 Harness 管理

启动应用后打开 `/admin.html`，选择「Agent 与 Harness」，或直接访问 `/agent-admin.html`。沿用部署环境的 `ADMIN_KEY`；生产环境未配置密钥时拒绝管理访问。本地开发默认密钥为 `anhao-admin`。页面不会提供云端密钥的读取或编辑功能。

## 可调整的配置

| 配置 | 行为与范围 |
| --- | --- |
| AI 总开关 | 控制开场建议、回复建议及自动代回的模型调用 |
| 供应商与模型 | Anthropic / DeepSeek；空模型名使用所选供应商的默认解析规则 |
| 自动代回总开关 | 允许或禁止自动代回；允许后仍需用户在每个会话明确同意开启 |
| 超时 | 1000–60000 毫秒 |
| 最大输出 Token | 256–8192 |
| 并发 | 1–8，共同约束开场、建议回复、自动代回及切换时仍在运行的旧请求 |
| UTC 日请求额度 | 全局 0–10000，每用户 0–1000；0 表示禁止请求；失败及已预占请求计入额度 |
| 三类提示词补充 | 开场建议、普通回复建议、自动代回各最多 2000 字；附加在固定规则之后，固定的同意、标识、输出校验、审核与接管规则继续适用 |

本页管理线上模型运行时 Harness 参数。研发任务 Harness（`npm run harness` 的任务阶段、源码指纹、验证脚本）及工作流源码继续通过仓库代码迭代维护；管理页面不执行任意脚本或改写源文件。

## 保存、冲突与恢复

修改后先校验，再查看变更对比、填写原因并确认保存。取消不会生效；重置草稿只改变表单。后台使用版本号控制更新，其他窗口已保存时返回冲突，需要重新加载后再修改。

配置和历史保存在 `DATA_DIR/anhao.db` 的 `agent_config_revisions`。首次启动从部署环境初始化，此后持久化版本是应用运行配置来源；重新部署或修改同名环境参数不会覆盖已有后台版本。凭证、供应商端点、磁盘路径和管理密钥始终由部署环境提供，不进入可编辑配置。历史界面展示最近 100 条记录；恢复会创建新版本，保留旧版本及恢复来源，且重新校验当前环境凭证。

新配置用于后续请求。配置切换使此前生成中的建议和自动回复失效；底层请求会被取消，若供应商未及时响应取消，仍占用共享并发，直到实际结束。切换不清空每日用量，不会重复发送旧回复。

关闭 AI 或自动代回总开关，会停止已开启的自动代回；重新允许不会替用户重新授权开启。调整其他参数不代替原会话同意。现有草稿和历史消息不会被新提示词改写。

## 凭证与验证

DeepSeek 使用 `DEEPSEEK_API_KEY`，Anthropic 使用环境中的 `ANTHROPIC_API_KEY` 或 `ANTHROPIC_AUTH_TOKEN`。后台仅显示对应凭证是否存在。切换供应商前需在部署平台配置该供应商凭证；启用配置必须通过环境与云端地址校验。

「校验」只检查字段、范围和环境配置，不发模型请求；`connectionVerified:false` 不表示已经连通。后台不提供读取真实聊天后自动测试的操作。模型接通验证仍使用显式授权的合成输入冒烟。

`npm run ai:doctor` / `ai:smoke` 是独立命令，读取命令运行环境，不能代替对后台当前持久化版本的检查。应用 `/api/ai/status` 及管理页面展示应用当前运行状态。

## 运维边界

- 只运行一个服务实例；将 `DATA_DIR` 与 SQLite 数据库一起持久化和备份。
- 管理接口使用 `x-admin-key`；写接口拒绝不匹配的浏览器 Origin。密钥只保留于当前浏览器会话，退出后清除。
- 所有操作者共享管理密钥，历史记录包含时间、原因和配置版本，尚未提供多管理员身份与角色权限。
- 调整配置不会发起付费批量评测，也不会改变已有内容审核与用户同意要求。
