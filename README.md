# 暗号

暗号是一个由真实内容停留与感受驱动的闭测社交产品。当前版本已经从静态原型升级为可持久化的全栈 MVP。

当前分支 `experiment/signal-conversation-mvp` 用于验证新的锋利定位：不再要求用户无限刷内容训练画像，而是让用户从每日 3 条精选内容或自己带来的外部链接中，留下一句真实表达，并与在同一处停下来的人完成一次有内容起点的对话。原版入口仍保留在 `/index.html`，`main` 分支没有被修改。

内测内容池目前包含 24 条真实可播放的短内容，覆盖生活节奏、关系态度、城市观察、运动、阅读、动物、科技、幽默和人生选择等主题。每条内容都配置了可用于验证回声链路的测试停留，但不会伪装成真实线上用户。

- 持久化聊天与实时新消息

- 昵称、简介、回答和聊天内容审核
- 注册到真实聊天的关键漏斗埋点
- 内测数据和举报处理后台

## 配置

复制 `.env.example` 中需要的配置到部署平台的环境变量。服务本身不自动读取 `.env` 文件，生产环境应由部署平台注入变量。

- `SMS_WEBHOOK_URL`：短信服务适配器地址，会收到 `{ phone, code }`
- `WECHAT_APP_ID`、`WECHAT_APP_SECRET`：微信认证服务号或公众号凭证
- `PUBLIC_URL`：公网 HTTPS 地址，用于微信回调
- `DATA_DIR`：持久化磁盘目录
- `ADMIN_KEY`：内测数据后台的管理密钥
- `BETA_TEST_CODE`：可选的 6 位统一闭测验证码；配置后生产环境不会发送短信，也不会把验证码返回给页面
- `MODERATION_WEBHOOK_URL`：可选的第三方内容审核适配器
- `DEMO_MATCHING_ENABLED`：仅用于本地演示；生产环境默认关闭，真实闭测不要开启

未配置短信服务时，非生产环境返回固定测试验证码；线上小规模闭测可以临时配置 `BETA_TEST_CODE`。统一验证码不验证手机号所有权，拿到邀请码和测试码的人可以用任意未注册手机号创建账号，因此只适合受控内测，接入正式短信后应移除。未配置微信凭证时，界面会说明该能力尚未启用。

## 内测数据后台

打开 [http://127.0.0.1:4173/admin.html](http://127.0.0.1:4173/admin.html)。本地默认管理密钥是 `anhao-admin`，正式部署必须通过 `ADMIN_KEY` 换成长随机密钥。

后台展示注册、资料完成、留下感受、进入回声、共同回答和真实聊天漏斗，也可以处理用户举报。审核默认使用内置规则；配置 `MODERATION_WEBHOOK_URL` 后会优先调用外部审核服务，并在不可用时回退到内置规则。

## 部署提示

这个版本需要 Node 服务和持久化磁盘，不能再只使用 GitHub Pages。正式部署还需要 HTTPS、短信服务、微信回调域名、数据库备份、接口限流和隐私协议。当前设备通知依赖页面保持打开；App 关闭后的系统推送需要继续接入 APNs、FCM 或微信服务通知。

Railway 部署时将持久化磁盘挂载到 `/data`，并设置 `DATA_DIR=/data`、`NODE_ENV=production`、`MASTER_INVITE_CODE`、`BETA_TEST_CODE` 和 `ADMIN_KEY`。生产环境默认监听 `0.0.0.0`，端口由部署平台的 `PORT` 环境变量提供。
